Below is a roadmap for CADL implementation and practical deployment,
considering the research directions in Chapter 9.

  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Phase**      **Goal**                                         **Content**
  -------------- ------------------------------------------------ --------------------------------------------------------------------------------------------------------------------------------------
  Phase 1\       Language Core Design and Parser Implementation   EBNF finalization, parser implementation, type checker implementation. Initial evaluation via MAPF simulator integration.
  (2026 Q2-Q3)

  Phase 2\       Verification Engine (Basic)                      SMT-based consistency verification, protocol deadlock detection. Verification experiments on robot delivery scenarios.
  (2026 Q3-Q4)

  Phase 3\       Runtime and Code Generation                      Python/TypeScript runtime generation, contract monitoring implementation. Demonstration on IoT data sharing scenarios.
  (2027 Q1-Q2)

  Phase 4\       AI Integration                                   NL→CADL conversion via LLM, regime recommendation engine. Evaluation on household rule design scenarios.
  (2027 Q2-Q3)

  Phase 5\       Institutional Transition and Regime Maps         Safety verification of dynamic institutional switching, regime map construction support tool. Integrated experiments across domains.
  (2027 Q3-Q4)

  Phase 6\       IEC 62853 Integration and Practical Deployment   Assurance case integration, smart contract generation. Real-world pilot projects.
  (2028 Q1-)
  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
