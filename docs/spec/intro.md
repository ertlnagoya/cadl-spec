# CADL: Contract Architecture Description Language

**Language Specification — Version 0.1 (Draft)**

Graduate School of Informatics, Nagoya University — ERTL

March 17, 2026

---

This document presents the first draft of the CADL language specification, covering language objectives, requirements, syntax and semantics definitions, and toolchain design.

CADL is a domain-specific language (DSL) for formally specifying, verifying, and deploying institutional designs in System of Systems (SoS).
