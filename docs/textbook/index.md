# Introduction

> **Audience**: Undergraduates and beginning graduate students who have just been introduced to System of Systems (SoS) thinking. No CADL experience required.
>
> **Duration**: about 95 minutes — a 5-minute setup plus six 15-minute steps.
>
> **What you take home**: A working CADL specification you wrote yourself, a generated Unity C# implementation, and a running 5-robot delivery simulation in which missed deadlines and battery-rule violations are detected and the affected contract instances are moved to `Violated`.
>
> **First time here?** The recommended order is [Why SoS-DSL?](../handson/academic-background.md) → [Architecture & Code Walkthrough](../handson/code-walkthrough.md) → this course. Reading the walkthrough before you start is recommended: it shows which part of the system each Step touches.

## How this textbook is organised

This textbook combines the Course A hands-on (Steps 0–6) with the exercises of a five-session class on the same robot-delivery system.

| --- | --- |
| I. Foundations | [1. What is an SoS?](01-what-is-sos.md) · [2. The toolchain and setup](02-toolchain-setup.md) · [3. Essentials of CADL](03-cadl-essentials.md) |
| II. Practice | [4. Writing the structure](04-structure.md) · [5. Writing the norms](05-norms.md) · [6. Visualising the lifecycle](06-visualise.md) · [7. Generating code and running the reference runtime](07-codegen-runtime.md) · [8. Running the simulation in Unity](08-unity.md) · [9. Improving the specification](09-improve.md) |

| Appendices | [A. Glossary](appendix-a-glossary.md) · [B. Using this textbook in a class](appendix-b-teaching.md) |

There are two ways to use it:

- **Self-study (about 95 minutes)**: follow Chapters 1–8 and skip the exercises at the end of each chapter.
- **A class (five sessions, or three)**: each of Chapters 4–9 is one session; the exercises at the end of the chapter are done in class and as homework. See [Appendix B](appendix-b-teaching.md).
