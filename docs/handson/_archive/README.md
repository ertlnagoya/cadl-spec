# Archive

This directory holds draft and historical documents from the SoS-DSL
development process. They are **not** part of the published hands-on
course; consult the rest of `docs/handson/` for the canonical materials.

The frontmatter on every file in this directory sets `draft: true`
and `unlisted: true` so that Docusaurus excludes them from the
generated site (and from search) while keeping them git-tracked.

| File | What it is |
| --- | --- |
| `sos-contract-dsl-design.md` | Initial R&D notes from the first session, before Appendix E was drafted. Now superseded by Appendix E and the PBL course design document. |
| `sos-dsl-pr-drafts.md` | PR-body templates used for the initial 5-repository submission. Useful as a starting point for future feature PRs. |
| `sos-dsl-unity-runbook.md` | Standalone Unity walkthrough; the same material now lives in Step 6 of the main hands-on textbook. |
