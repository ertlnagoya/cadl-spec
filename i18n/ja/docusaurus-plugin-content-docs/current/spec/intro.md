# CADL: Contract Architecture Description Language

**言語仕様書 — Version 0.1 (ドラフト)**

名古屋大学大学院情報学研究科 ERTL

2026年3月17日

---

本文書はCADL言語仕様の初版ドラフトです。言語の目的、要件、構文・意味論の定義、およびツールチェーンの設計を記述しています。

CADL（Contract Architecture Description Language）は、System of Systems（SoS）における制度設計を形式的に記述・検証・展開するためのドメイン特化言語（DSL）です。
