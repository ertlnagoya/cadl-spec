# 10. 実装ロードマップ

CADLの実装と実用化に向けたロードマップを以下に示す。第9章の研究方向性も考慮した計画である。

| **フェーズ** | **目標** | **内容** |
|---|---|---|
| Phase 1（2026 Q2-Q3） | 言語コア設計・パーサ実装 | EBNF確定，パーサ実装，型検査器実装。MAPFシミュレータとの連携による初期評価。 |
| Phase 2（2026 Q3-Q4） | 検証エンジン（基本） | SMTベース無矛盾性検証，プロトコルデッドロック検出。ロボット配送シナリオでの検証実験。 |
| Phase 3（2027 Q1-Q2） | ランタイム・コード生成 | Python/TypeScriptランタイム生成，契約監視器実装。IoTデータ共有シナリオでの実証。 |
| Phase 4（2027 Q2-Q3） | AI統合 | LLMによるNL→CADL変換，制度推薦エンジン。家庭内ルール設計シナリオでの評価。 |
| Phase 5（2027 Q3-Q4） | 制度遷移・モードマップ | 動的制度切替の安全性検証，モードマップ構築支援ツール。複数ドメインでの統合実験。 |
| Phase 6（2028 Q1-） | IEC 62853連携・実用化 | アシュアランスケース連動，スマートコントラクト生成。実世界パイロットプロジェクト。 |
